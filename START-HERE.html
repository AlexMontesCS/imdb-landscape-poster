IMDb Landscape Worker

This page gives you the visible Cloudflare deployment button. Cloudflare requires the project to be in a public GitHub or GitLab repository before the button can deploy it.

1. Create the repository

Create a public repository named imdb-landscape-worker, then upload every file from this unzipped folder.

Create GitHub repository

2. Paste the repository URL

Example: https://github.com/alex/imdb-landscape-worker

3. Deploy

The button becomes active after you enter a valid GitHub or GitLab repository URL.
